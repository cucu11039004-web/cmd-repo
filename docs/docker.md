# Docker

先确保已安装 Docker，并且 Docker 服务已经启动。

### 查看正在运行的容器

```bash
docker ps
```

- 作用：显示运行中的容器、镜像、状态和端口映射；加上 `-a` 可以包含已停止的容器。
- 遇到场景：启动服务后，想确认容器是否正常运行以及对外开放哪个端口。
- 来源：命令速查表建站示例。

### 查看容器最近的日志

```bash
docker logs --tail 50 容器名
```

- 作用：查看指定容器最近 50 行日志；把 `容器名` 换成 `docker ps -a` 中的真实名称或 ID。
- 遇到场景：容器启动后退出，或者服务访问失败，需要检查错误信息。
- 来源：命令速查表建站示例。
