# Vim

在服务器上编辑配置文件，或者在本机练习模态编辑。键位写法：普通模式直接写按键，如 `dw`；`<C-r>` 表示 Control+r；以 `:` 开头的是命令行模式命令。

## 模式切换

普通模式、插入模式、可视模式、命令行模式之间的切换。

## 光标移动

按字符、单词、行、段落、屏幕移动，跳到行首、行尾和指定行。

## 编辑与操作符

`d`、`c`、`y` 等操作符和动作组合，删除、修改、复制和粘贴。

## 文本对象

`iw`、`i"`、`ap` 等文本对象，一次选中单词、引号内容或段落。

## 搜索与替换

`/` 搜索、`*` 搜当前单词、`:s` 和 `:%s` 替换。

## 可视模式

字符、行、块选择，以及对选区的批量操作。

## 寄存器与宏

用寄存器保存多段文本，录制并重放宏。

## 文件、缓冲区与窗口

保存、退出、打开多个文件，分屏和切换窗口。

## 常用配置

`~/.vimrc` 常用设置，比如行号、缩进和搜索高亮。
