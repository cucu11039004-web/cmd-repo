# 正则表达式

Vim、rg、sed 和 Python 都会用到的正则表达式。各工具的语法略有差异，见最后一节。

## 字符与字符类

`.`、`\d`、`\w`、`\s`、`[abc]`、`[^abc]` 等匹配单个字符的写法。

## 量词

`*`、`+`、`?`、`{n,m}`，以及贪婪与非贪婪匹配。

## 锚点与边界

`^`、`$`、`\b`，匹配行首、行尾和单词边界。

## 分组与引用

捕获组、非捕获组、命名组，以及在替换中引用分组。

## 环视

前瞻和后顾：只在前后满足条件时匹配。

## 各工具写法差异

同一个需求在 Vim、rg、sed、Python `re` 里的不同写法和转义规则。
