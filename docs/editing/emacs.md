# Emacs 键位

HHKB 上 Control 在 A 键左边，Emacs 键位按起来很顺手。键位写法：`C-x` 表示 Control+x，`M-x` 表示 Meta+x（Mac 上是 Option 或先按 Esc），`C-x C-s` 表示依次按两组组合键。

## 终端与 macOS 通用键位

在 zsh、bash 命令行和 macOS 的大多数输入框里也能用的 Emacs 键位。

## 光标移动

按字符、单词、行首行尾、整屏移动光标。

### 光标移动到下一行 { #emacs-ctrl-n }

```bash
C-n
```

- 作用：光标移到下一行
- 遇到场景：在终端或 Emacs 里移动光标
- 来源：待补充

## 编辑与删除

删除字符、单词和整行，交换字符，改变大小写。

## 选区、剪切与粘贴

设置标记、剪切（kill）、粘贴（yank）和循环粘贴历史。

## 搜索与替换

增量搜索、反向搜索、交互式替换。

## 文件与缓冲区

打开、保存文件，在缓冲区之间切换。

## 窗口

分割窗口、在窗口间切换、关闭窗口。

## 撤销、取消与帮助

撤销、取消当前命令，查看某个键位或函数的帮助。
