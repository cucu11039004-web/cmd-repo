# 命令速查表

遇到一个有用的命令，记下它解决了什么问题。需要时回来查，真正的练习留在终端里。

## 从场景开始查

| 我想做什么 | 去哪里找 |
| --- | --- |
| 临时记一条，还没想好分类 | [收集箱](inbox.md) |
| 看目录、找文件 | [Linux 文件操作](linux-files.md) |
| 找端口占用、检查网络响应 | [Linux 进程与网络](linux-process-network.md) |
| 查看改动、回看提交记录 | [Git](git.md) |
| 查看容器、排查运行日志 | [Docker](docker.md) |
| 创建和使用虚拟环境 | [Python 环境](python-env.md) |

也可以直接用页面顶部的搜索框搜索 `lsof`、`git` 或“端口”。代码块右上角可以复制命令。

## 遇到就记

配置好终端函数后，用单引号包住要记录的内容，避免反引号和 `$` 被终端解释为命令或变量：

```bash
note 'lsof -i :8000 查端口占用；场景：本地服务启动失败；来源：本次学习'
```

准备公开时再执行：

```bash
notepush
```

每周把 [收集箱](inbox.md) 中的记录补全，移到对应分类；确认已经归档后删除临时条目，保留收集箱标题和说明。

## 固定条目格式

“遇到场景”最重要：记住什么时候用，比只记命令更容易复习。下面的“来源”是填写示例，请替换成真实学习经历。

````markdown
### 查看谁占用了某个端口

```bash
lsof -i :8000
```

- 作用：查看使用 8000 端口的进程及 PID。
- 遇到场景：本地服务启动时报 address already in use。
- 来源：填写本次学习或可公开的项目名。
````
