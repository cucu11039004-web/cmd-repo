# Shell 与终端

zsh 和 bash 的通用用法。命令行里的光标移动、删除等键位见 [Emacs 键位](../editing/emacs.md)。

## 重定向与管道

`>`、`>>`、`2>&1`、`|`，把输出写进文件或交给下一条命令。

## 历史与补全

搜索和复用历史命令，善用 Tab 补全。

## 别名与函数

`alias` 和 shell 函数，把常用的长命令缩短。

## 环境变量与配置文件

`export`、`PATH`、`~/.zshrc`、`~/.bashrc`，以及让修改生效的方法。

## 引号与通配符

单引号、双引号、`*`、`?` 的区别，避免变量和通配符被意外展开。

## 脚本基础

写 shell 脚本：参数、条件、循环和 `set -euo pipefail`。
