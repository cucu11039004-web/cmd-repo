# Linux 文件操作

以下基础命令也可以在 macOS 终端中使用。示例来源仅表示建站演示，不代表你的学习经历。

### 查看目录里的全部文件

```bash
ls -la
```

- 作用：以详细列表显示当前目录内容，包括以点开头的隐藏文件。
- 遇到场景：想确认项目里有没有 `.gitignore`，或查看文件权限。
- 来源：命令速查表建站示例。

### 按名称查找 Markdown 文件

```bash
find . -type f -name '*.md'
```

- 作用：从当前目录向下查找所有以 `.md` 结尾的文件；引号让通配符交给 `find` 处理。
- 遇到场景：文档分散在多个子目录，不知道某篇笔记放在哪里。
- 来源：命令速查表建站示例。
